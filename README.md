# meu_portifolio
Este projeto foi desenvolvido como uma atividade prática de estudos em HTML e CSS.

O objetivo da atividade foi colocar em prática conceitos de desenvolvimento web, como a criação de páginas HTML, organização de conteúdo, navegação entre páginas, utilização de CSS para estilização e estruturação de um pequeno site.

## Páginas do projeto

- Sobre mim
- Projetos
- Contato
- Agradecimento

## Tecnologias utilizadas

- HTML5
- CSS3
